点餐与外卖：堂食扫码点餐（桌码绑定桌号）、外卖配送/自提，支持微信、支付宝小程序双端。订单统一进入收银台，可混合结算。

多店管理：总部统一配置菜品、价格、营销活动，分店独立接单、独立打印、独立对账。单店版关闭总部模块即可降级使用，数据靠store_id隔离。
